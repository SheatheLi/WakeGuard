# Shutdown与任务受理的竞争验证

`tests/test_stop_admission_race.cpp`使用C++20 Barrier让生产者和停止线程同时启动，比较四种现有执行器在`submit`/`request_stop`交错下的行为。检查停止后拒绝新任务，以及每个成功受理任务对应Future最终变为Ready，并核对实际执行数量。

运行：`cmake -S . -B build && cmake --build build -j2 && ctest --test-dir build --output-on-failure`

**限制**：这只是给定环境中的重复压力测试，不是对所有Weak Memory执行、调度公平和无死锁性质的形式化证明。当前Pool文档约束外部唯一所有者Join，不能并发析构。
